# Казань и Саранск — десять пространств моды

Десять отдельных сайтов свадебных салонов, студий никаха, вечерней моды и ателье, созданных по предоставленным заказчиком материалам. Разные композиции и цветовые палитры, адаптация под телефон, удобные контакты, FAQ и подготовка обращения на примерку. Галереи с просмотром фотографий, избранное, подбор образа и отдельные сценарии примерки, визита без записи и аренды.

Изображения созданы встроенным ImageGen как редакционные образы для вдохновения. Они не являются реальными фотографиями товаров или портфолио компаний. Цены — ориентиры из предоставленных данных; наличие и условия подтверждает салон. Формы только составляют текст для копирования, не отправляют данные и не подтверждают запись. Ссылки компаний используются в общем списке; по ним не выполнялся поиск.
